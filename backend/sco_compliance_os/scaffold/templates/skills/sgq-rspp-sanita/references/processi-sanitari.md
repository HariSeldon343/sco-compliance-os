# Processi Sanitari — Mappa di Riferimento

## Processi primari (clinico-assistenziali)

### Macroprocesso di presa in carico

```
Accettazione/Accoglienza → Valutazione iniziale → Pianificazione cura → Erogazione prestazioni → Dimissione/Follow-up
```

### Dettaglio per fase

| Fase | Attività | Documenti SGQ | Documenti Sicurezza |
|---|---|---|---|
| Accettazione/Accoglienza | Registrazione anagrafica, triage (PS), prenotazione, accettazione amministrativa, informazione paziente | PO-ACC-xxx, MOD-ACC-xxx | Protocolli sicurezza area accettazione |
| Valutazione iniziale | Anamnesi, esame obiettivo, valutazione infermieristica (scale di rischio: Braden, Conley, NRS, Morse, Barthel), richiesta esami | PR-VAL-xxx, MOD-VAL-xxx | DVR area degenza, rischio biologico |
| Pianificazione cura | Definizione piano diagnostico-terapeutico, consenso informato, PDTA se applicabile, coinvolgimento specialisti | PG-PIA-xxx, PDTA-xxx, MOD-CON-xxx | Valutazione rischi trattamenti specifici |
| Erogazione prestazioni | Prestazioni diagnostiche, terapeutiche, assistenziali, chirurgiche, riabilitative | PO/PR per specialità, IO-xxx | DVR specifici per area, DPI, protocolli emergenza |
| Dimissione/Follow-up | Lettera di dimissione, istruzioni al paziente, continuità assistenziale, comunicazione MMG/PLS, follow-up ambulatoriale | PO-DIM-xxx, MOD-DIM-xxx | — |

## Sette principi della qualità — Declinazione sanitaria

| Principio ISO 9000 | Declinazione sanitaria | Interfaccia sicurezza |
|---|---|---|
| Focalizzazione sul cliente | Centralità paziente; percorso assistenziale personalizzato; consenso informato; carta dei servizi; URP; gestione reclami; customer satisfaction | La sicurezza del lavoratore è precondizione per la sicurezza del paziente |
| Leadership | Direzione Generale/Sanitaria/Amministrativa; Clinical Governance; commitment Direttori UO/Dipartimento | DL obblighi art. 17-18, designazione RSPP, MC |
| Partecipazione delle persone | Coinvolgimento personale sanitario/tecnico/amministrativo; ECM; empowerment; clima organizzativo | RLS, consultazione lavoratori, segnalazione rischi |
| Approccio per processi | Processi clinico-assistenziali (PDTA), di supporto (farmacia, sterilizzazione, laboratorio), gestionali | Processi di sicurezza integrati nei processi operativi |
| Miglioramento | MCQ; PDCA; audit clinici; M&M review; incident reporting; gestione eventi avversi e near-miss | Piano di miglioramento sicurezza, riduzione infortuni |
| Decisioni basate su evidenze | EBM; EBN; indicatori clinici/esito (PNE, SDO); KPI | Dati infortuni, MP, near-miss, misurazioni ambientali |
| Gestione delle relazioni | Fornitori sanitari; convenzioni SSN; enti regolatori; associazioni pazienti | Gestione interferenze fornitori (DUVRI), coordinamento |
