# Processi Sanitari — Mappa di Riferimento per SGQ

Mappa dei processi tipici di una struttura sanitaria, articolata in processi primari (clinico-assistenziali), di supporto e gestionali. Da adattare alla specifica struttura e ai servizi nello scope del SGQ.

---

## 1. Processi primari (clinico-assistenziali)

Sono i processi che creano direttamente valore per il paziente — il "core business" della struttura sanitaria.

### 1.1 Percorso del paziente — Flusso generale

```
Accesso/Accoglienza → Valutazione iniziale → Pianificazione cura → Erogazione prestazioni → Dimissione/Follow-up
```

### 1.2 Dettaglio processi primari per setting

| Processo | Descrizione | Clausole ISO 9001 | Rischi tipici |
|----------|-------------|-------------------|---------------|
| **Accettazione e accoglienza** | Prenotazione (CUP), accettazione amministrativa, triage (PS), presa in carico, assegnazione posto letto | 8.2.1, 8.2.2 | Errore identificazione, mancata raccolta anamnesi critica |
| **Valutazione iniziale** | Anamnesi, esame obiettivo, richiesta accertamenti, valutazione multidimensionale (geriatria/riabilitazione) | 8.2.2, 8.2.3 | Valutazione incompleta, mancato riconoscimento urgenza |
| **Pianificazione della cura** | Definizione piano diagnostico-terapeutico, consenso informato, pianificazione intervento/trattamento, applicazione PDTA | 8.1, 8.3 | Inappropriatezza, mancato consenso, piano non personalizzato |
| **Erogazione prestazioni cliniche** | Visite, trattamenti, interventi chirurgici, procedure diagnostiche/terapeutiche, somministrazione farmaci, assistenza infermieristica | 8.5.1 | Errore terapeutico, errore chirurgico, ICA, cadute |
| **Attività diagnostica** | Laboratorio analisi, diagnostica per immagini, anatomia patologica, altre indagini | 8.5.1, 8.5.2 | Errore pre-analitico, scambio campioni, referto errato |
| **Attività chirurgica** | Blocco operatorio: preparazione, anestesia, intervento, risveglio, recovery | 8.5.1, 8.5.2, 8.5.6 | Wrong site/side/patient, complicanze anestesiologiche |
| **Gestione farmaci** | Prescrizione, preparazione, somministrazione, monitoraggio effetti | 8.5.1, 8.5.3 | Errore prescrizione/somministrazione, interazioni, allergie |
| **Dimissione e continuità** | Lettera dimissione, istruzioni al paziente, follow-up, continuità con territorio (MMG, ADI) | 8.5.5 | Dimissione prematura, mancata comunicazione al territorio |
| **Gestione emergenza-urgenza** | Triage, stabilizzazione, percorsi tempo-dipendenti (STEMI, ictus, trauma) | 8.5.1, 8.2.1 | Sotto-triage, ritardo trattamento |

### 1.3 Processi primari per tipologia struttura

| Struttura | Processi primari caratterizzanti |
|-----------|--------------------------------|
| Ospedale per acuti | Emergenza-urgenza, degenza medica/chirurgica, blocco operatorio, terapia intensiva, day hospital/surgery |
| Casa di cura privata | Degenza medica/chirurgica, day hospital/surgery, ambulatori specialistici |
| Poliambulatorio | Visite specialistiche, diagnostica strumentale, piccola chirurgia ambulatoriale |
| RSA | Assistenza residenziale, riabilitazione, cure palliative, attività socio-sanitarie |
| Struttura riabilitativa | Riabilitazione intensiva/estensiva, valutazione multidimensionale, progetto riabilitativo |
| Laboratorio analisi | Pre-analitica, analitica, post-analitica, refertazione |
| Centro diagnostico | Diagnostica per immagini, diagnostica funzionale, refertazione |

## 4. Interazioni critiche tra processi

Le interazioni tra processi sono particolarmente critiche in sanità per la sicurezza del paziente:

| Interazione | Rischi | Strumenti di gestione |
|-------------|--------|----------------------|
| Reparto → Blocco operatorio | Wrong patient/site/side | Checklist chirurgica OMS, time-out |
| Reparto → Laboratorio | Scambio campioni, pre-analitica | Protocollo identificazione, etichettatura |
| Medico → Farmacia → Infermiere | Errori prescrizione/somministrazione | Riconciliazione farmacologica, doppio controllo |
| PS → Reparto (handover) | Perdita informazioni cliniche | SBAR, checklist handover |
| Dimissione → Territorio | Discontinuità assistenziale | Lettera dimissione strutturata, follow-up |
| Sterilizzazione → Blocco operatorio | Strumentario non sterile | Tracciabilità lotto, indicatori sterilizzazione |
| Diagnostica → Clinico | Referto errato o ritardato | Protocollo comunicazione valori critici |
